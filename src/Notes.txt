Redux and Redux Toolkit :

Redux VS Redux Toolkit :
1. Both have same purpose and Use
2. We need to write more code in Redux having so much code complexity. So for make easy make a wrapper which is Redux Toolkit.
3. Redux toolkit is wrapper of Redux.
4. In Redux we need to defined Action and Reducer  but in Toolkit action and reducer come under slice. Comes in a file.

If we want to send the data to redux then we send by dispatch from UI and comes under action.
And Action is a data that we want to store , add or save data
Reducer helps to store the data in reducer and whenever we want that data .

The major changes in redux toolkit (compare to redux) is action and reducers we use in one file and one type we use in slice : slice = action + reducer.
Slice like food cutting slice specific eg. search slice, user authentication slice, product slice.

Store : that data comes in store and we can use that data if we want from a component.
